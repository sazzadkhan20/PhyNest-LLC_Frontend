# PHYNEST LLC Website

Static website for **PHYNEST LLC** — property maintenance and preservation services.

Built with plain **HTML + CSS** (minimal vanilla JavaScript for menu, FAQ, and form). No frameworks.

## Pages

- `index.html` — Landing page (hero, services, about, FAQs, contact, map, footer)
- `privacy-policy.html` — Privacy policy

## Deploy

Upload the whole project folder to any static host (Apache, Nginx, Netlify, cPanel, etc.):

```
index.html
privacy-policy.html
css/styles.css
js/main.js
Resources/   ← keep image files as-is
```

Open `index.html` as the site root. No build step required.

## Local preview

```bash
python -m http.server 8765
```

Then visit `http://localhost:8765`
